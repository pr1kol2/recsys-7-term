# ДЗ 1 Гринько Кирилл Андреевич

Сравниваю ItemKNN, iALS, EASE, FM и ALS с таргетом из оценки и давности отзыва на [Amazon Video Games 2014](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon/links.html). Подготовка данных, формулы и эксперименты находятся в [experiments.ipynb](experiments.ipynb), реализации моделей — в `models/`.

В выборке 186 358 оценок, 33 616 пользователей и 3997 товаров. Рекомендую по 10 товаров, которые пользователь ещё не оценивал; положительным считаю отзыв на 4 или 5. Train заканчивается 1 июля 2013 года, validation — 1 января 2014 года. Параметры выбираю по NDCG@10 на validation, после чего переобучаю модели на train + validation.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run_notebook.py
```

## Результаты на test

| Модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| EASE | 0.04968 | 0.08249 |
| CustomALS | 0.04403 | 0.07620 |
| iALS | 0.04342 | 0.07436 |
| ItemKNN | 0.04232 | 0.07289 |
| FM | 0.04046 | 0.07437 |

На этом разбиении лучший результат у EASE с reg=50. Новый таргет ALS при тех же параметрах не дал улучшения. У FM добавление категорий повысило NDCG на 0.00404, но 95% bootstrap-интервал разницы пересекает ноль. Подробные сравнения с вариантами без категорий и без нового таргета есть в конце ноутбука.

Каталог ограничен популярными в train товарами, пользователи — теми, у кого уже есть история. Категории считаю статическими: в датасете нет их исторических версий. На новых пользователей и товары эти результаты переносить нельзя.
